# 📌 Contact Book

A command-line contact management system built in Python.
This project allows users to store, view, update, and delete contacts in a simple and organized way.

---

## 🎯 Objective
The goal of this project was to practice core Python fundamentals while building a functional real-world application.
Instead of only studying theory, I applied programming logic to create a system that simulates how contact management works.
---

## 🧠 What I Learned
- Working with functions to organize code
- Using dictionaries and lists to store structured data
- File handling for data persistence
- Creating interactive command-line menus
- Input validation and error handling
- Writing cleaner and more readable code

This project helped me move from “just learning syntax” to actually thinking like a programmer.

---

## 🛠️ Technologies Used
Python
File system (data storage)
Command Line Interface (CLI)
Git & GitHub
---

## ⚙️ How It Works
1. The program displays a menu with options
2. The user can:
Add a new contact
View all contacts
Search for a contact
Edit contact information
Delete a contact
3. The contact data is stored so it can be reused later
4. The system validates user input to prevent errors
